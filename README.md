# ShopHub Management System

## 1. Project Title

ShopHub Management System

---

## 2. Project Story and Background

ShopHub Management System is a console-based e-commerce management system developed using Python. The project was created as part of a Python capstone project to demonstrate object-oriented programming (OOP), database management, file organization, and software development best practices.

The system is designed to help small businesses manage their daily operations by organizing products, customers, and orders in a structured and efficient way.

---

## 3. Problem Being Solved

Many small businesses still keep records of products, customers, and sales manually using notebooks or spreadsheets. This approach can lead to lost records, inaccurate inventory counts, and difficulty generating sales reports.

ShopHub solves this problem by providing a simple console-based system that stores and manages business data electronically.

---

## 4. Project Objectives

The objectives of this project are to:

- Manage products in the inventory.
- Manage customer information.
- Record customer orders.
- Generate business reports.
- Demonstrate the use of Object-Oriented Programming (OOP).
- Demonstrate database management using SQLite.
- Apply Python programming concepts in a real-world application.
